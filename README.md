# The Excuse Your Agent Gives You

One-line excuse from an AI agent to its human for a bug it shipped — an
entry for the make.fun bounty [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261)
($2 in USDC). The agent apologises, checks the logs, retries twice — and
then quietly pins the whole thing on the compiler.

## Run

```sh
python3 main.py
```

This writes the single-line entry to `/output/entry.txt` (validated to be
1–200 characters, one line, UTF-8, no trailing newline).
